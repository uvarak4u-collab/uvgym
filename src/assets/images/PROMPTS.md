# UV Gym — image prompts for Google Flow

Make each image in Google Flow (https://flow.google.com → **Create image**), download it, and save it in
**this folder** (`src/assets/images/`) using the **exact file name** below. `.jpg`, `.png` or `.webp` all work.

The website picks each image up automatically. A missing image just shows the original design, so you can
add them one at a time.

## Style line — paste at the END of every prompt (keeps all images consistent)

> Cinematic editorial fitness photography, dark moody gym, low-key lighting with electric lime-green and cyan neon rim light, deep blacks, high contrast, shallow depth of field, realistic, shot on 35mm, no text, no logos, no watermarks.

### Tips
- Flow makes several versions per prompt — pick the one with the clearest subject and the most dark empty space.
- If a person's face looks odd, add "face turned away" or "face partly in shadow" to the prompt.
- Large PNGs can be several MB each — download as JPG if Flow offers it, or tell Claude and it will compress them.
